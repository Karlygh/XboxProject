# 🎮 Xbox Games — Página de Exploración del Catálogo

Aplicación web inspirada en Xbox que permite explorar el catálogo de juegos, mostrando precios, descripciones y tráilers. La interfaz cuenta con **efectos parallax** y **carruseles interactivos**, ofreciendo una experiencia visual moderna y atractiva.

## Características

- Exploración de juegos con información detallada (nombre, precio, descripción, tráiler).  
- Interfaz visual con **efectos parallax** y **carruseles de juegos**.  
- Navegación fluida y moderna.  
- Inspirada en el diseño de la plataforma Xbox.  

## Tecnologías

- Angular  
- HTML5, CSS3 y JavaScript/TypeScript  
- Librerías para efectos visuales y carruseles  

## Instalación

1. Clonar el repositorio:

```bash
git clone https://github.com/tu-usuario/xbox-games.git
cd xbox-games
```

2. Instalar dependencias:

```bash
npm install
```

3. Iniciar la aplicación en modo desarrollo:

```bash
ng serve
```

4. Abrir en el navegador:

```
http://localhost:4200
```

## Uso

- Explora los juegos disponibles en el catálogo.  
- Visualiza precios, descripciones y tráilers de manera interactiva.  
- Navega por los carruseles y disfruta de los efectos parallax en la interfaz.
